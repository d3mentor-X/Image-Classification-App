# AI Image Classification App

A simple AI-powered image classification application that can analyze images provided by the user and identify what is present in them.

The project was developed as a practical machine learning/AI project with a simple interface for testing image classification through uploaded images and camera input.

## Features

- Upload an image for classification
- Capture an image using the camera
- Analyze the provided image using an AI image classification model
- Display the classification result through a simple user interface
- Easy-to-use interface for testing different images

## Technologies Used

- Python
- Streamlit
- Machine Learning / AI
- Image Processing
- Pillow
- NumPy
